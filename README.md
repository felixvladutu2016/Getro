# SPACE SHADOWS

Un joc 2D realist sci‑fi inspirat de social deduction.

## Caracteristici
- gameplay impostor vs crew
- hartă spațială futuristă
- UI holografic
- atmosferă cinematică
- stil realist modern

## Concept
Jucătorii trebuie să repare sistemele unei stații spațiale în timp ce sabotori încearcă să elimine echipajul fără să fie descoperiți.

## Gameplay
### Crew
- repară sisteme
- termină task-uri
- votează suspecți

### Sabotor
- elimină echipajul
- sabotează reactorul
- evită camerele video

## Stil vizual
- neon albastru și roșu
- texturi metalice
- top-down 2D
- efecte cinematice
